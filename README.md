# agent-skills
Agent-Skills: Repo with agent skills for claude/codex.

## Skills

| Skill | What it is |
|---|---|
| [claude-agents-md](claude-agents-md) | Installer for a shared `CLAUDE.md` / `AGENTS.md` rules file (coding guidelines, git/PR conventions, bash/Containerfile/podman-compose/README rules). `install.sh` asks for Claude, Codex or both and copies `CLAUDE.md` to `~/.claude/CLAUDE.md` and/or `AGENTS.md` to `~/.codex/AGENTS.md`. |
| [loop-backlog](loop-backlog) | Slash command `/cc-loop-backlog` plus a `cc-loop-backlog.sh` runner that reads `backlog.md` in the current directory, reports TODO/WIP counts, and drives Claude Code to work through the backlog until done, streaming progress from the CLI's JSON output. `install.sh` asks for Claude, Codex or both, installs the runner to `~/Documents/bin` and the command to `~/.claude/commands` and/or `~/.codex/prompts`. |
| [bundle-size](bundle-size) | Skill that attributes a frontend project's JS bundle size to the imports that caused it. Bundles the project with esbuild, reads the metafile, and renders a light-theme site ranking every import by minified KB. `install.sh` asks for Claude, Codex or both, copies the skill to `~/.claude/skills` and/or `~/.codex/skills`, and runs `npm install`. |
| [rerender](rerender) | Skill that benchmarks React re-renders. Mounts each component in jsdom inside a React Profiler, forces parent re-renders with stable props, counts wasted renders, and renders a Lighthouse-style light-theme report. `install.sh` asks for Claude, Codex or both, copies the skill to `~/.claude/skills` and/or `~/.codex/skills`, and runs `npm install`. |
| [bug-recording](bug-recording) | Skill that runs a target React app, hunts for CSS/functional/render bugs with Playwright, and records a narrated video of each one. `install.sh` asks for Claude, Codex or both, copies the skill to `~/.claude/skills` and/or `~/.codex/skills`, runs `npm install`, and installs the Playwright Chromium browser. |
| [html-research](html-research) | Skill and `/html-research` command that researches a topic on the web and renders one self-contained light-theme HTML report: searchable cards with click-through detail modals, 5 pros / 5 cons / 5-10 gaps per card, a mandatory `What The Industry Does` section covering big tech and AI labs, handwritten SVG diagrams, embedded favicon, and a clickable source for every claim. `install.sh [claude|codex|both]` asks for Claude, Codex or both when no argument is given, and copies the skill to `~/.claude/skills` and/or `~/.codex/skills` and the command to `~/.claude/commands` and/or `~/.codex/prompts`. |
| [scripts-skill](scripts-skill) | Skill that gives a fullstack app one predictable set of operational scripts in `scripts/`: `setup.sh`, `start-all.sh`, `stop-all.sh`, `test-all.sh`, `status.sh` (every port UP or DOWN with its pid), `ui.sh`, and `sql-console.sh` when the app has a database. Ports live in `scripts/ports.env`, every script resolves the app root from its own location so it runs from any directory of the repo, and the set is documented at the end of the app `README.md`. `install.sh [claude|codex|both]` asks for Claude, Codex or both when no argument is given, and copies the skill to `~/.claude/skills` and/or `~/.codex/skills`. |
| [bash-skill](bash-skill) | Skill with the rules for writing bash scripts: no comments, no sleeps longer than 1 second, poll podman/k8s resources in a loop instead of waiting, no emojis unless asked, no timeouts over a minute. `install.sh` asks for Claude, Codex or both and copies the skill to `~/.claude/skills` and/or `~/.codex/skills`. |
| [changelog-skill](changelog-skill) | Skill that writes and updates `CHANGELOG.md`: newest version first, only `Added` / `Changed` / `Fixed` / `Verified` sections, every `Fixed` entry saying what broke, why, and what happens now, and a `Verified` section that lists only what was actually run. `install.sh` asks for Claude, Codex or both and copies the skill to `~/.claude/skills` and/or `~/.codex/skills`. |
| [container-skill](container-skill) | Skill for containerized solutions: `Containerfile` instead of `Dockerfile`, podman and podman-compose instead of docker, latest versions, no comments, plus `start.sh`, `stop.sh` and `test.sh` around the compose file. `install.sh` asks for Claude, Codex or both and copies the skill to `~/.claude/skills` and/or `~/.codex/skills`. |
| [git-gh-skill](git-gh-skill) | Skill with the git and `gh` conventions: merge only and never rebase, commit messages prefixed with the project name and no `Co-Authored-By` lines, and PRs that carry the task summary, the full prompt and the real test output. `install.sh` asks for Claude, Codex or both and copies the skill to `~/.claude/skills` and/or `~/.codex/skills`. |
| [index-html-skill](index-html-skill) | Skill for building a self-contained `index.html`: light theme by default, CSS and JS inlined in the single file, and code blocks rendered with syntax highlighting and line numbers. `install.sh` asks for Claude, Codex or both and copies the skill to `~/.claude/skills` and/or `~/.codex/skills`. |
| [readme-skill](readme-skill) | Skill that writes a project `README.md`: logo first, then what the project does, how it works, architecture as an Excalidraw-style hand-drawn diagram instead of ASCII art, features, stack, APIs, how to run, and Playwright screenshots of every UI tab rendered inline. `install.sh` asks for Claude, Codex or both and copies the skill to `~/.claude/skills` and/or `~/.codex/skills`. |
| [macos-electron-apps](macos-electron-apps) | Skill with the rules for macOS and Electron apps: light theme, rounded logo, install/uninstall scripts that guarantee a single installed version and a single running instance, restored window position, working copy/paste, and the standard `CMD + k` / `CMD + /` / zoom / tab / screenshot / fullscreen shortcuts. `install.sh` asks for Claude, Codex or both and copies the skill to `~/.claude/skills` and/or `~/.codex/skills`. |
| [commands](commands) | Slash commands shared across agents. `/do <prompt>` reads or creates a design doc, adds the request to `backlog.md` under `TODO` / `WIP` / `DONE`, implements it, keeps the build and tests green, and updates the readme, changelog and backlog. `install.sh` asks for Claude, Codex or both and copies the commands to `~/.claude/commands` and/or `~/.codex/prompts`. |
| [fact-checker](fact-checker) | Skill and `/fact-check` command that adversarially checks the claims in an HTML report, a URL, a path or a plain prompt. Every claim becomes a numbered fact (`F1: is Google just a search engine?`), is researched on the web for and against, and is ruled `true`, `false`, `partly` or `unverifiable` — no source means unverifiable, never true. Contradicting facts are flagged on both cards and the True and False groups are triple checked. Renders one self-contained light-theme HTML report with a verdict scoreboard, a search box over every fact, and one clickable card per fact into `~/git/diegopacheco/html-research/`. Follows the [html-research](html-research) report contract. `install.sh [claude|codex|both]` asks for Claude, Codex or both when no argument is given. |
