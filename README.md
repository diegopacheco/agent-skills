# agent-skills
Agent-Skills: Repo with agent skills for claude/codex.

## Skills

| Skill | What it is |
|---|---|
| [claude-agents-md](claude-agents-md) | Installer for a shared `CLAUDE.md` / `AGENTS.md` rules file (coding guidelines, git/PR conventions, bash/Containerfile/podman-compose/README rules). `install.sh` asks for Claude, Codex or both and copies `CLAUDE.md` to `~/.claude/CLAUDE.md` and/or `AGENTS.md` to `~/.codex/AGENTS.md`. |
| [loop-backlog](loop-backlog) | Slash command `/cc-loop-backlog` plus a `cc-loop-backlog.sh` runner that reads `backlog.md` in the current directory, reports TODO/WIP counts, and drives Claude Code to work through the backlog until done, streaming progress from the CLI's JSON output. `install.sh` asks for Claude, Codex or both, installs the runner to `~/Documents/bin` and the command to `~/.claude/commands` and/or `~/.codex/prompts`. |
| [bundle-size](bundle-size) | Skill that attributes a frontend project's JS bundle size to the imports that caused it. Bundles the project with esbuild, reads the metafile, and renders a light-theme site ranking every import by minified KB. `install.sh` asks for Claude, Codex or both, copies the skill to `~/.claude/skills` and/or `~/.codex/skills`, and runs `npm install`. |
| [rerender](rerender) | Skill that benchmarks React re-renders. Mounts each component in jsdom inside a React Profiler, forces parent re-renders with stable props, counts wasted renders, and renders a Lighthouse-style light-theme report. `install.sh` asks for Claude, Codex or both, copies the skill to `~/.claude/skills` and/or `~/.codex/skills`, and runs `npm install`. |
| [bug-recording](bug-recording) | Skill that runs a target React app, hunts for CSS/functional/render bugs with Playwright, and records a narrated video of each one. `install.sh` asks for Claude, Codex or both, copies the skill to `~/.claude/skills` and/or `~/.codex/skills`, runs `npm install`, and installs the Playwright Chromium browser. |
| [html-research](html-research) | Skill and `/html-research` command that researches a topic on the web and renders one self-contained light-theme HTML report: searchable cards with click-through detail modals, 5 pros / 5 cons / 5-10 gaps per card, a mandatory `What The Industry Does` section covering big tech and AI labs, handwritten SVG diagrams, embedded favicon, and a clickable source for every claim. `install.sh [claude|codex|both]` asks for Claude, Codex or both when no argument is given, and copies the skill to `~/.claude/skills` and/or `~/.codex/skills` and the command to `~/.claude/commands` and/or `~/.codex/prompts`. |
| [scripts-skill](scripts-skill) | Skill that gives a fullstack app one predictable set of operational scripts in `scripts/`: `setup.sh`, `start-all.sh`, `stop-all.sh`, `test-all.sh`, `status.sh` (every port UP or DOWN with its pid), `ui.sh`, and `sql-console.sh` when the app has a database. Ports live in `scripts/ports.env`, every script resolves the app root from its own location so it runs from any directory of the repo, and the set is documented at the end of the app `README.md`. `install.sh [claude|codex|both]` asks for Claude, Codex or both when no argument is given, and copies the skill to `~/.claude/skills` and/or `~/.codex/skills`. |
| [bash-skill](bash-skill) | Skill with the rules for writing bash scripts: no comments, no sleeps longer than 1 second, poll podman/k8s resources in a loop instead of waiting, no emojis unless asked, no timeouts over a minute. `install.sh` asks for Claude, Codex or both and copies the skill to `~/.claude/skills` and/or `~/.codex/skills`. |
| [changelog-skill](changelog-skill) | Skill that writes and updates `CHANGELOG.md`: newest version first, only `Added` / `Changed` / `Fixed` / `Verified` sections, every `Fixed` entry saying what broke, why, and what happens now, and a `Verified` section that lists only what was actually run. `install.sh` asks for Claude, Codex or both and copies the skill to `~/.claude/skills` and/or `~/.codex/skills`. |
| [container-skill](container-skill) | Skill for containerized solutions: `Containerfile` instead of `Dockerfile`, podman and podman-compose instead of docker, latest versions, no comments, plus `start.sh`, `stop.sh` and `test.sh` around the compose file. `install.sh` asks for Claude, Codex or both and copies the skill to `~/.claude/skills` and/or `~/.codex/skills`. |
| [git-gh-skill](git-gh-skill) | Skill with the git and `gh` conventions: merge only and never rebase, commit messages prefixed with the project name and no `Co-Authored-By` lines, and PRs that carry the task summary, the full prompt and the real test output. `install.sh` asks for Claude, Codex or both and copies the skill to `~/.claude/skills` and/or `~/.codex/skills`. |
| [stacks-skill](stacks-skill) | Skill with predefined stacks: `java` (Java 25, Maven, Spring Boot 4.1.x, Spring Data JDBC, Postgres, HikariCP), `scala` (Scala 3.x, sbt, Netty, Spring Boot 4.x, Postgres, HikariCP), `kotlin` (Kotlin 2.x, Java 25, Gradle wrapper, Spring Boot 4.1.x, Postgres, HikariCP), `ts` (TypeScript 7.x, Bun 2.x, Vite, React 19.3.x, TanStack 1.x), `nodejs` (Node.js 26, npm, TypeScript 7.x, Express), `rust` (Rust 1.99.x edition 2024, Tokio, async, `Result`, traits), `go` (Go 1.26.x) and `python` (Python 3.15.x, uv, ty, Granian, tests), all with modular code and proper types. Refer to one as `java stack` or `java-stack`; when the stack is unclear the agent asks you to pick one. `install.sh [claude|codex|both]` and `uninstall.sh [claude|codex|both]` ask for Claude, Codex or both when no argument is given, and copy the skill to or remove it from `~/.claude/skills` and/or `~/.codex/skills`. |
| [index-html-skill](index-html-skill) | Skill for building a self-contained `index.html`: light theme by default, CSS and JS inlined in the single file, and code blocks rendered with syntax highlighting and line numbers. `install.sh` asks for Claude, Codex or both and copies the skill to `~/.claude/skills` and/or `~/.codex/skills`. |
| [readme-skill](readme-skill) | Skill that writes a project `README.md`: logo first, then what the project does, how it works, architecture as an Excalidraw-style hand-drawn diagram instead of ASCII art, features, stack, APIs, how to run, and Playwright screenshots of every UI tab rendered inline. `install.sh` asks for Claude, Codex or both and copies the skill to `~/.claude/skills` and/or `~/.codex/skills`. |
| [macos-electron-apps](macos-electron-apps) | Skill with the rules for macOS and Electron apps: light theme, rounded logo, install/uninstall scripts that guarantee a single installed version and a single running instance, restored window position, working copy/paste, and the standard `CMD + k` / `CMD + /` / zoom / tab / screenshot / fullscreen shortcuts. `install.sh` asks for Claude, Codex or both and copies the skill to `~/.claude/skills` and/or `~/.codex/skills`. |
| [commands](commands) | Slash commands shared across agents. `/do <prompt>` reads or creates a design doc, adds the request to `backlog.md` under `TODO` / `WIP` / `DONE`, implements it, keeps the build and tests green, and updates the readme, changelog and backlog. `install.sh` asks for Claude, Codex or both and copies the commands to `~/.claude/commands` and/or `~/.codex/prompts`. |
| [fact-checker](fact-checker) | Skill and `/fact-check` command that adversarially checks the claims in an HTML report, a URL, a path or a plain prompt. Every claim becomes a numbered fact (`F1: is Google just a search engine?`), is researched on the web for and against, and is ruled `true`, `false`, `partly` or `unverifiable` — no source means unverifiable, never true. Contradicting facts are flagged on both cards and the True and False groups are triple checked. Renders one self-contained light-theme HTML report with a verdict scoreboard, a search box over every fact, and one clickable card per fact into `~/git/diegopacheco/html-research/`. Follows the [html-research](html-research) report contract. `install.sh [claude|codex|both]` asks for Claude, Codex or both when no argument is given. |
| [night-agents](night-agents) | Eleven night agent skills for Claude and Codex - `code-digger-agent` (dead code), `presto-performance-agent` (performance), `migration-bot-agent` (dependency bumps and migrations), `test-automator-agent` (missing tests), `worm-doccer` (docs in sync with code), `bug-hunter` (bugs fixed with TDD), `architect-agent` (architecture, design, extensibility, separation of concerns and cohesion review) `smith-sec-agent` (OWASP Top 10 and zero day security review) `code-review-agent` (full code review: bugs, design, logical fallacies, anti-patterns, broken requirements, missing tests, fixed and reported), `test-review-agent` (flaky tests, tests of the language or framework, weak tests) and `chief-of-staff-agent` (adversarial review of the other agents: gaps, contradictions, merge conflicts) - run with `/night-agents all`, `/night-agents <alias>` or `/night-agents` to pick. Each agent works in its own git worktree and branch, runs the tests before and after, documents its work, and records the run under `~/.night-agents/runs/<date>/<project>/`. A pregenerated light-theme macOS Electron app shows a GitHub-style nightly activity grid, every agent branch with syntax highlight, line numbers, rendered markdown and HTML, and search, and metrics with trends. Ships a sample project with planted problems. `install.sh [claude|codex|both]`. |
| [night-agents/skills/night-agents](night-agents/skills/night-agents) | Skill and `/night-agents` dispatcher that runs one, several or all of the eleven night agents against the current git repository, each on its own branch and worktree, and records every run under `~/.night-agents/runs/<date>/`. Run with `/night-agents all`, `/night-agents <alias>` or `/night-agents` to pick. Installed by [night-agents](night-agents) `install.sh [claude|codex|both]`. |
| [night-agents/skills/code-digger-agent](night-agents/skills/code-digger-agent) | Skill `/code-digger-agent` (`/night-agents digger`) that finds unused classes, methods, functions, variables, parameters, imports, files, exports and dependencies, writes tests that prove the code is dead, runs the suite before and after removal, and leaves the cleanup on its own branch with a report. Installed by [night-agents](night-agents) `install.sh [claude|codex|both]`. |
| [night-agents/skills/presto-performance-agent](night-agents/skills/presto-performance-agent) | Skill `/presto-performance-agent` (`/night-agents presto`) that hunts missing database indexes, N+1 queries, database access in loops, missing pagination, quadratic algorithms, wrong data structures, missing caching, blocking IO and oversized assets, then measures, fixes, measures again and runs the tests on its own branch with a report. Installed by [night-agents](night-agents) `install.sh [claude|codex|both]`. |
| [night-agents/skills/migration-bot-agent](night-agents/skills/migration-bot-agent) | Skill `/migration-bot-agent` (`/night-agents migration`) that lists every outdated dependency, runtime and build plugin, runs the suite first, bumps them one by one to the latest stable version, performs the code migrations the breaking changes require, and runs the suite after each bump on its own branch with a report. Installed by [night-agents](night-agents) `install.sh [claude|codex|both]`. |
| [night-agents/skills/test-automator-agent](night-agents/skills/test-automator-agent) | Skill `/test-automator-agent` (`/night-agents tests`) that finds core logic with no tests and adds unit, property based, integration, stress, chaos, contract, CSS and UI tests without duplicating existing ones, running the suite and coverage before and after on its own branch with a report. Installed by [night-agents](night-agents) `install.sh [claude|codex|both]`. |
| [night-agents/skills/worm-doccer](night-agents/skills/worm-doccer) | Skill `/worm-doccer` (`/night-agents docs`) that checks every claim in `README.md`, `docs/`, `performance.md`, `backlog.md`, `design-doc.md`, `CHANGELOG.md` and API docs against the code and rewrites what drifted, on its own branch with a report. Installed by [night-agents](night-agents) `install.sh [claude|codex|both]`. |
| [night-agents/skills/bug-hunter](night-agents/skills/bug-hunter) | Skill `/bug-hunter` (`/night-agents bugs`) that hunts wrong logic, off by one, money rounding, time zones, null handling, races, unvalidated input, error paths and resource leaks, writes `bug-report.md`, and fixes each bug with TDD on its own branch with a report. Installed by [night-agents](night-agents) `install.sh [claude|codex|both]`. |
| [night-agents/skills/architect-agent](night-agents/skills/architect-agent) | Skill `/architect-agent` (`/night-agents architect`) that reviews extensibility, separation of concerns, cohesion, coupling, layering, dependency direction, abstractions and module boundaries, proves every finding with file and line evidence, and writes `architecture-review.md` on its own branch without changing code. Installed by [night-agents](night-agents) `install.sh [claude|codex|both]`. |
| [night-agents/skills/smith-sec-agent](night-agents/skills/smith-sec-agent) | Skill `/smith-sec-agent` (`/night-agents sec`) that hunts the OWASP Top 10 plus zero day classes like prototype pollution, deserialization, path traversal and ReDoS, proves each one locally without attacking anything, and writes `security-report.md` on its own branch without changing code. Installed by [night-agents](night-agents) `install.sh [claude|codex|both]`. |
| [night-agents/skills/code-review-agent](night-agents/skills/code-review-agent) | Skill `/code-review-agent` (`/night-agents review`) that reviews all the code like a senior reviewer - bugs, design problems, logical fallacies, anti-patterns, broken requirements and missing tests - fixes each finding it can prove with a test, reports the rest, and writes `code-review.md` on its own branch. Installed by [night-agents](night-agents) `install.sh [claude|codex|both]`. |
| [night-agents/skills/test-review-agent](night-agents/skills/test-review-agent) | Skill `/test-review-agent` (`/night-agents test-review`) that runs the suite many times to hunt flaky tests, deletes tests that only exercise the language or framework, rewrites tests that cannot fail, and strengthens weak assertions, on its own branch with `test-review.md`. Installed by [night-agents](night-agents) `install.sh [claude|codex|both]`. |
| [night-agents/skills/chief-of-staff-agent](night-agents/skills/chief-of-staff-agent) | Skill `/chief-of-staff-agent` (`/night-agents chief`) that adversarially reviews the other night agents' latest runs, branches and reports, re-checks their claims, re-runs their tests, finds gaps, contradictions and merge conflicts, and writes `chief-of-staff-review.md` on its own branch without changing code. Installed by [night-agents](night-agents) `install.sh [claude|codex|both]`. |
