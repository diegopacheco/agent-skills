installOne binary. Always fresh.

ram is an npx-style installer in Rust. Every run pulls the latest commit of this repo, so new skills show up with no release step.

Pick a target

Claude, Codex or both. One choice decides where everything lands.

Search & check

Full-screen picker. Type to filter, tab by kind, space to toggle, → to read the whole SKILL.md first.

Install in parallel

Copies and npm install run concurrently. Fails loud with the reason.

Prefer no tools? Every folder ships an install.sh [claude|codex|both].

night agentsThe night shift.

Each agent works in its own git worktree and branch, runs the tests before and after, and leaves a report. You review in the morning.

night-agents

Dispatcher. /night-agents all, one alias, or pick. Records runs under ~/.night-agents/runs.

code-digger-agent

Finds dead code, proves it with tests, removes it.

presto-performance-agent

N+1s, missing indexes, quadratic loops. Measure, fix, measure again.

migration-bot-agent

Bumps deps one by one, migrates breaking changes, tests after each.

test-automator-agent

Adds the tests that matter to untested core logic.

worm-doccer

Checks every doc claim against the code and fixes what drifted.

bug-hunter

Off-by-ones, rounding, races, null paths. Fixed with TDD.

architect-agent

Coupling, cohesion, layering. Every finding with file and line.

smith-sec-agent

OWASP Top 10 plus zero-day classes, proven locally.

code-review-agent

Senior-style full review. Fixes what it can prove with a test.

test-review-agent

Hunts flaky tests and rewrites tests that cannot fail.

chief-of-staff-agent

Reviews the other agents. Gaps, contradictions, merge conflicts.
